# eu-tech-reg

An open, structured map of EU technology regulation — AI, data, privacy, security, products and
machinery — that points to the official sources. For people learning it and for agents consulting
it (MCP from the start).

**Status:** idea, 2026-11-14. See [docs/wip/IDEA.md](docs/wip/IDEA.md).

**Not legal advice.** Every fact here links to its official source and the date it was read; the
official text is what counts.
