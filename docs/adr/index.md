# Decisions (ADR)

Decisions that shape the *structure* of this project: what is in scope, how it is organised,
what conventions govern it. The rule of thumb: would a future contributor need to know this to
make a consistent change? Then it is an ADR.

ADRs are append-only: a changed decision is a new ADR that supersedes the old one.

## Format

`ADR-NNNN-short-slug.md`, numbered sequentially, never renumbered. Copy `ADR_TEMPLATE.md` from
this directory and read the notes at its bottom first.
