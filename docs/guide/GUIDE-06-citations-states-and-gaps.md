# 06 · Citations, states and gaps

The map tells you where it is sure, where it is not yet, and where it has not looked. It uses the
same few marks everywhere, so you learn them once.

## The citation line

The small line under a fact says where it comes from: the article, and the act that set it. For the
AI Act's dates, that is a point of Article 113 and either the AI Act itself or the Digital Omnibus
that changed it. Follow the link to read the text; the official text is what counts.

## The marks

| You see | It means |
| --- | --- |
| A **solid** line or dot, *applies* / *in force* | That part applies today |
| A **dashed** line or ring, *not yet* | It applies from a later date |
| *Not yet:* before an act's name, dashed underline | That act is not on the map yet |
| *Explanation draft · not yet reviewed* in a dashed box | The plain-words text has not been checked |
| *Obligations not yet broken down* | The article is listed; its duties are not yet written out — read the article |
| *Not yet read* | The map has not read that act's definitions yet |

## What is never shown

A fact the map has not checked against the official text is not shown at all. You will see the gap
marked instead.
