# Proposals (RFC)

Proposals that need a "should we?" review before becoming decisions. An RFC closes into one or
more [ADRs](../adr/index.md) if accepted, or is deleted if rejected (with a brief rationale in the
closing commit).

## Format

`RFC-NNN-short-slug.md`, numbered sequentially, never renumbered. Copy `RFC_TEMPLATE.md` from
this directory and read the notes at its bottom first.
